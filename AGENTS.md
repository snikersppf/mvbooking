# Project Instructions

- Проект — MVP сервиса аренды автомобилей в Грузии.
- Финального дизайна пока нет.
- Использовать Next.js, TypeScript, PostgreSQL и Prisma.
- Сначала реализовывать архитектуру и бизнес-логику, затем временный интерфейс.
- Не добавлять сложный визуальный дизайн до появления дизайн-макетов.
- Не использовать реальные секреты и ключи в коде.
- Все изменения проверять через lint, typecheck, test и build.
- Работать небольшими этапами и показывать измененные файлы.

- Спецификация: `docs/mvp-spec.md`; план архитектуры: `docs/architecture.md`.
- До утверждения плана изменять только документацию и правила хранения файлов; бизнес-код и миграции не реализовывать.
- Все текстовые файлы сохранять в UTF-8 без BOM, с LF и завершающим переводом строки.
- Для установленной версии Next.js (см. `package.json`) читать соответствующие локальные руководства в `node_modules/next/dist/docs/` и официальную документацию перед реализацией.
- В Next.js 16 использовать `proxy.ts` для предварительных перенаправлений; роль и статус проверять в БД в каждой защищённой серверной операции.
